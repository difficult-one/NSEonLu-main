# 放大波形的 Ctrl 缩放

状态：用户已确认推荐方案，实现与软件验证已完成。

## 建议交互

放大弹窗中，鼠标位于波形绘图区时，Ctrl + 滚轮以鼠标指向的采样时间为中心缩放时间轴。向上滚动放大细节，向下缩小，范围限制为 100 ms 到 60 s。纵轴按可见数据自动适配。弹窗内 Ctrl + 加号/减号以图中心缩放，Ctrl + 0 和“恢复全图”按钮恢复 60 s。

弹窗打开期间截获 Ctrl + 滚轮及上述三个缩放快捷键，避免触发浏览器页面缩放；普通滚轮保持正常滚动。关闭弹窗后恢复浏览器快捷键。每次重新打开图表恢复全图。

缩放只改变放大图的显示范围，普通卡片继续显示最近 60 秒。实时模式的范围相对窗口末端保持并随时间前进；暂停模式保持冻结快照，缩放不会恢复采集画面。悬停按新的时间范围查询真实采样，保留无效值、断点和 500 ms 空白规则。坐标标签标明相对当前显示窗口末端的时间，避免把历史范围误标为“现在”。

## 方案取舍

推荐时间轴缩放并自动适配纵轴，方便查看采样细节且操作单一。双轴同时围绕鼠标缩放能单独放大振幅，但容易把其他曲线移出视野，需要额外的平移和复位交互，本次不默认加入。

## 实现与验证

charts.js 接收可选时间范围，并让绘图和悬停使用同一范围；app.js 管理弹窗范围、非 passive 的 wheel 监听、键盘快捷键和复位入口。保持现有本地脚本、串口协议与滚动存储。

浏览器验证 Ctrl + 滚轮只改变时间范围且阻止默认事件，页面尺寸/缩放比例不变；检查鼠标锚点、缩放上下限、键盘缩放/复位、关闭后的默认快捷键、暂停缩放、实时滚动以及悬停时间/读数一致。运行现有图表与串口浏览器回归，只提交本次网页和文档。

验证记录：新增 zoom-check、现有 chart-check 和 browser-check 均在隔离 Edge 中通过；17 项 Node 开发测试通过。实际 Ctrl + 滚轮及键盘操作后，页面尺寸、devicePixelRatio 和 visualViewport.scale 保持不变。独立审查指出缩放边缘切入断点的情况，已用左右边缘失败用例复现；悬停改为从完整快照判断相邻分段，再限制读数只能来自可见范围，回归通过。桌面及 375px 截图已人工检查。
