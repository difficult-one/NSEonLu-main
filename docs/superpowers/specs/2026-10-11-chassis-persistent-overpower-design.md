# 持续超功率的负向纠偏

## 问题与范围

阶段 3 在实测功率超过基准预算时暂停慢环，快保护又没有积分，持续模型偏差可能留下残余超限。用户已在确认原因和负向纠偏方向后要求修复。

修复只增加阶段 3 的持续超限负向通道，不改变阶段 0/1/2 的慢环行为，不调整现有模型、PID、预算来源或用户正在修改的参数。

## 控制行为

- 快保护继续即时处理超限；启动容忍与短时尖峰不进入慢环积分。
- 功率计和四轮反馈新鲜、控制周期有效、存在驱动且没有制动、已退出启动容忍，实测功率连续高于目标加共享死区达到现有 `stable_run_ms`（默认 100 ms）后，瞬态模块允许负向学习。
- 重复的陈旧功率样本、无驱动、制动、停机、启动或非法周期均中断连续确认。时间差使用无符号差值，支持 tick 回绕。
- 新鲜功率样本升高并进一步加深快保护时重新确认，包含已有 CLAMP 中的尖峰。进入新的负向确认窗口时以当前实测功率重置慢环滤波，避免把尖峰滤波拖尾写入积分。
- 共享阈值升高时重新确认；降低阈值保留确认，避免超容预算持续下降时无法纠偏。快照发布确认阈值，底盘拒绝低于当前阈值的旧确认结果。
- 阶段 3 的负向通道还要求两个不同功率样本完成恢复，并且原始及滤波功率都超过目标加死区。它绕过模型限幅与需求门槛，补偿上限为 0 W，不产生正向学习。
- 持续超限期间不执行低需求回零，避免衰减抵消负积分。退出负向通道后沿用原有慢环学习与低需求衰减。
- 快保护不会写回慢积分；积分回算仍只跟踪慢环自身限幅及限速。

## 验证

使用真实快保护和慢环函数建立主机集成回归，覆盖持续超限收敛、模型未限幅/需求不足、正历史撤销、短时尖峰冻结、启动、制动、无驱动、陈旧反馈、异常周期、停机和 tick 回绕。使用简单可控功率响应验证收敛，不将该响应视作实机性能结论。
