# USB 网页在线调参

在现有本地仪表盘增加 PID、功控和小陀螺参数，修改实时生效，不写 Flash。

采用实时监测、在线调参两个页签，共享连接栏和关键遥测卡片。调参页使用侧边分组导航和宽表单，每组独立读取、编辑、撤销、应用。PID 覆盖底盘四轮速度环，每轮 Kp/Ki/Kd、输出限幅、积分限幅、死区；误差单位为度/秒。功控覆盖慢外环及电容/缓冲预算主要调节量；硬保护和裁判限制保持原有控制职责。小陀螺支持当前编译模式的参数，不在运行时切换算法。

候选布局还有常驻窄侧栏和弹窗；前者拥挤，后者不便持续调试，因此选择独立页签。切换页签不停止采集。

沿用 Web Serial / USB CDC，全双工使用 @T1 前缀行协议，与 CSV v1 分流。请求包含唯一 ID、组名、操作、组版本及整组值，版本防止旧草稿覆盖。浮点值使用 IEEE754 float32 的八位十六进制表示，避免嵌入式浮点 printf。响应包含实际生效值、版本及编译模式，回执前不宣称成功。

USB ISR 只复制字节到固定容量接收环。遥测任务解析、格式化回复，电机任务在计算前应用 PID，底盘任务在周期开始应用功控和自旋参数。整组验证通过才修改，拒绝非有限数、越界、字段数错误及组合约束冲突。更新后清除相关积分和学习状态，自旋保持既有斜率保护，预算观察器历史保留。

重连读取实际值；遥测任务检测断线后清理未处理请求，已应用值继续留在 RAM，重启恢复固件默认。演示模式不下发参数，旧固件无回执显示超时并允许重新读取。编辑形成草稿，点击应用才下发。自旋运行时拒绝改变方向，改参清理学习状态后从上一输出按速率过渡，停机不延迟。

用户补充要求将网页修改同步到文件。板端确认后，浏览器把确认值交给本地服务，同源 POST /api/tuning 原子修改 modules/telemetry/tuning_overrides.h 对应组，其他组保持。固件初始化验证这些覆盖值，通过才作为启动默认；文件更新需重新编译、烧录才进入固件。文件失败与板端失败独立显示并可重试，重新 GET 后更新待同步记录。接口限制本机同源、固定路径、固定组和完整字段校验，仍不写板端 Flash。
