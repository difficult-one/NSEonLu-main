函数声明：
void CalcOffsetAngle();                  // 计算偏移角度
                                          // 根据gimbal传回的当前电机角度计算和零位的误差
                                          // 分为三种情况讨论（大于/小于/跨360度）
                                          // 将计算结果存入chassis_cmd_send.offset_angle

void RemoteControlSet();                 // 遥控器控制模式
                                          // 设置控制模式和控制量，来自robot_cmd.h中定义的模式
void MouseKeySet();                      // 键鼠控制模式
                                          // 键盘控制底盘速度、鼠标控制云台角度
void EmergencyHandler();                 // 紧急处理
                                          // 遥控器拨轮到底 → 所有模块进入stop状态

函数实现：
void RobotCMDInit()
S1: 调用RemoteControlInit()初始化遥控器，注意选用添加了反相器的串口
S2: 调用VisionInit()初始化视觉通信，注意选用正确的串口号
S3: CHASSIS, SHOOT, GIMBAL 各自注册发布者和订阅者（通过message_center）
    如果是双板通信(QIMBAL_BOARD)，还需要初始化CANComm进行跨板通信

void RobotCMDTask()                      // 主任务函数，200Hz运行
S1: 通过SubGetMessage获取所有模块的反馈数据（chassis/gimbal/shoot）
S2: 调用CalcOffsetAngle计算云台和底盘正方向的夹角
S3: 根据遥控器开关位置判断控制模式（遥控器/键鼠）
S4: 调用EmergencyHandler处理急停
S5: 通过PubPushMessage向各模块发布控制指令
