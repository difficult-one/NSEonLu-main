# 底盘功率模型双环控制设计

## 目标

在现有四轮 M3508 功率模型限流基础上增加功率计实测外环。内环继续在电机任务中快速完成四轮功率分配和电流反解；外环在底盘任务中根据实测总功率修正内环预算，补偿模型的稳态偏差，同时避免低负载积分饱和、功率计掉线突变和制动工况错误增益。

本次不修改 M3508 模型系数、四轮误差权重分配、超级电容预算策略或功率计 CAN 协议。

## 方案选择

采用“模型前馈 + 受限 PI 外环纠偏”。

- 现有功率模型作为 1 kHz 内环，负责快速响应电机电流和转速变化。
- 功率计反馈作为约 200 Hz 外环，只修正传给模型的总预算，不直接修改单个电机电流。
- 外环只在功率需求接近限制时工作；低负载时不把未使用功率当成需要积分消除的误差。
- 负向修正立即生效，正向修正限幅并限速，优先保证不超功率。

不采用直接把功率误差叠加到四轮电流。该方案绕过现有功率分配，会破坏四轮速度误差优先级，且难以保证模型输出和最终 CAN 电流的一致性。

不采用无条件 PI。机器人低负载时实测功率必然远低于上限，无条件积分会积累较大的正向修正，在下一次加速时造成瞬时超功率。

## 控制架构和周期

外环新增为与硬件无关的纯 C 算法模块：

- `modules/algorithm/chassis_power_outer_loop.h`
- `modules/algorithm/chassis_power_outer_loop.c`

`ChassisTask()` 每约 5 ms 更新一次超级电容预算和外环。外环读取功率计快照及上一电机周期的功率模型诊断值，输出修正后的模型预算，再调用 `DJIChassisPowerSetBudget()`。

`DJIMotorControl()` 每约 1 ms 使用修正后的预算运行现有 `PowerModelApply()`，完成四轮分配、电流反解和 CAN 输出。`PowerModelApply()` 不依赖功率计，也不增加跨任务控制逻辑。

数据流如下：

```text
裁判系统与超级电容
        |
        v
ChassisPowerBudgetUpdate() ----> 原始预算 B
                                      |
功率计实测 ----> 外环 PI 纠偏 --------+
                                      |
                                      v
                              修正后模型预算
                                      |
                                      v
                            PowerModelApply()
                                      |
                                      v
                               四轮电机电流
```

## 算法接口

外环模块提供配置、状态、输入和输出四个结构体，以及重置和更新两个接口。字段使用 `float`，功率单位统一为 W，时间单位统一为 s。

配置包含：

- 比例增益 `kp = 0.5`；
- 积分增益 `ki = 1.0 /s`；
- 实测功率低通时间常数 `measurement_lpf_tau_s = 0.030 s`；
- 外环激活余量 `activation_margin_w = 5.0 W`；
- 误差死区 `error_deadband_w = 1.0 W`；
- 最大正向预算修正 `max_positive_correction_w = 8.0 W`；
- 正向修正和负修正恢复到零的速率 `positive_slew_rate_w_per_s = 20.0 W/s`。

状态保存：

- 滤波后的实测功率；
- PI 积分项；
- 当前预算修正量；
- 上一周期原始预算；
- 功率计滤波器是否已经初始化。

每周期输入：

- 原始预算 `nominal_budget_w`；
- 安全目标功率 `target_power_w`；
- 功率计原始实测功率及在线标志；
- 模型预测的四轮未限幅需求总功率；
- 当前是否允许正向补偿；
- 底盘控制是否启用；
- 本周期 `dt_s`。

输出包含修正后模型预算、预算修正量、滤波功率、功率误差和 `OFFLINE`、`STANDBY`、`ACTIVE` 三态诊断状态。

## 外环目标

定义共享的底盘功率安全系数：

```text
eta = 0.95
```

同一常量同时用于现有内环配置和外环目标，避免两个 `0.95` 独立维护：

```text
B = chassis_budget_output.applied_budget_w
P_ref = eta * B
```

外环的名义输入仍为 `B`。在模型准确且功率需求充足时，内环有效预算为 `eta * B`，实测功率落在 `P_ref` 附近，外环修正为零。因此外环不会抵消既有的 5% 安全余量。

## 测量滤波和硬超限路径

有效功率计样本使用一阶低通：

```text
alpha = dt / (tau + dt)
P_filtered += alpha * (P_raw - P_filtered)
```

首次收到有效样本时直接令 `P_filtered = P_raw`，不从零开始爬升。

普通 PI 使用 `P_filtered`。若原始样本满足 `P_raw > B`，控制计算改用 `max(P_raw, P_filtered)`，使明显超过原始预算的瞬时功率无需等待滤波器即可触发负向修正。

## 激活条件

功率计在线、底盘控制启用且输入均为有限数时，满足下列任一条件才进入 `ACTIVE`：

```text
predicted_unlimited_power >= P_ref - 5 W
P_filtered                 >= P_ref - 5 W
P_raw                      >  B
```

正向修正还要求当前处于正向耗电工况。该标志由上一电机周期遥测计算：功率计功率非负，且四轮 `current_command * actual_speed_rpm` 之和非负。负功率、明显制动或回灌工况禁止产生新的正向积分。

未满足激活条件时进入 `STANDBY`：积分项清零，正修正立即撤销，负修正以 `20 W/s` 恢复到零。这样低负载不会积累功率补偿，同时模型低估产生的保守负修正也不会突然消失。

## PI 修正、限幅和抗饱和

活动状态下先计算：

```text
e = P_ref - P_control
```

当 `abs(e) <= 1 W` 时令 `e = 0`。否则：

```text
P_term = kp * e
I_candidate = I + ki * e * dt
C_candidate = P_term + I_candidate
```

修正量动态限制为：

```text
-B <= C <= 8 W
```

当候选输出已经到达上限且误差仍为正，或到达下限且误差仍为负时，拒绝本周期积分；误差推动输出离开饱和区时继续积分。积分项本身也限制在相同区间。

负向修正立即采用候选值。正向修正最多按 `20 W/s` 增长：

```text
C_next <= C_previous + 20 * dt
```

最终传给内环的预算为：

```text
corrected_budget = clamp(B + C_next, 0, B + 8 W)
```

外环从不直接生成电机电流。四轮功率优先级、方程求根和最终电流硬限幅仍完全由现有内环负责。

## 预算变化与状态复位

- 原始预算下降超过 `1 W` 时，立即清除正向积分和正向修正；负向修正可以保留。
- 原始预算上升时不制造额外修正，现有超级电容预算上升斜率继续生效。
- 零力或急停时调用外环重置，输出 0 W，并清空滤波、积分和修正状态。
- 功率计首次恢复在线时以首帧重新初始化滤波器，不沿用离线前的滤波值。

## 离线和异常处理

功率计离线、测量为 NaN 或无穷大时进入 `OFFLINE`：

- 积分清零；
- 正向修正立即变为零；
- 已存在的负向修正以 `20 W/s` 恢复到零；
- 最终退回保留 `0.95` 安全系数的模型单环。

配置非法、原始预算非有限或小于等于零时，更新接口返回失败并输出 0 W。异常 `dt` 不执行积分或正向增长；保留或加强已有负向修正，不产生新的正向修正。

当 `POWER_METER_ENABLE=0` 时，`chassis.c` 不初始化功率计，也不调用反馈外环，直接把原始预算交给现有模型，行为与改造前一致。

## 应用集成

`UpdateChassisPowerBudget()` 的顺序调整为：

1. 获取裁判系统和超级电容状态；
2. 更新 `ChassisPowerBudgetUpdate()`，得到原始预算；
3. 在启用功率计时获取一次一致的功率计快照；
4. 汇总上一电机周期的模型未限幅功率和耗电方向；
5. 更新外环并得到修正后预算；
6. 把修正后预算传给 `DJIChassisPowerSetBudget()`；
7. 把在线功率计实测值传给 `DJIChassisPowerSetMeasuredPower()`。

超级电容命令仍使用裁判系统选出的基础限制，不使用外环修正值。外环只约束 C 板上的四轮电机模型，不能改变超级电容控制板收到的裁判系统限制。

现有 19 列 RTT CSV 格式保持不变。最后一列仍表示百分之一瓦，但数据源由超级电容状态中的 `chassis_power_w` 改为在线功率计的 `power_w`；功率计离线时写入 0。

## TDD 与验证

主机测试按先失败、后最小实现的顺序覆盖：

1. 超功率产生负修正并降低模型预算；
2. 需求充足且功率不足时按斜率产生正修正；
3. 低负载不积分，修正回零；
4. 正修正不超过 `8 W`；
5. 负修正最低可把模型预算压到 0 W；
6. `1 W` 死区和 `30 ms` 一阶低通；
7. 上下限两侧的抗积分饱和；
8. 原始功率超过 `B` 时绕过滤波延迟产生负修正；
9. 负功率和制动工况不产生正修正；
10. 功率计离线时立即撤销正修正、缓慢释放负修正；
11. 功率计重新上线时重新初始化滤波；
12. 原始预算下降时清除正向状态；
13. 零力复位；
14. 空指针、非法配置、NaN、无穷大和异常 `dt`。

回归验证包括现有 `power_model`、`chassis_power_budget`、`power_meter`、`power_meter_protocol` 和 `chassis_power_feedback` 主机测试。最后分别以 `POWER_METER_ENABLE=1` 和 `POWER_METER_ENABLE=0` 构建 ARM 固件。

## 上板调试顺序

1. 架空车轮，以 60 W 台架预算检查外环状态和功率计方向；
2. 保持 `Ki = 0`，仅验证比例项在超功率时方向正确；
3. 启用 `Ki = 1.0 /s`，检查稳态误差是否收敛；
4. 依次测试低速直行、急加速、急刹车、横移和小陀螺；
5. 断开并恢复功率计，验证模型单环降级和无突跳恢复；
6. 切换裁判功率限制和超级电容可用功率，确认预算下降优先；
7. 根据 RTT 曲线只调整外环配置，不重新拟合本次范围外的模型系数。

## 完成标准

- 功率需求接近限制时，外环能把功率计稳态读数控制在 `0.95 * applied_budget_w` 附近；
- 低负载、负功率和制动工况不积累正向补偿；
- 瞬时超出原始预算时无需等待低通即可下调模型预算；
- 功率计离线不会停底盘，并能平滑退回模型单环；
- 外环输出始终位于 `[0, nominal_budget_w + 8 W]`；
- 原有内环异常保护和四轮分配行为保持不变；
- 新增测试、相关回归测试和两种功率计编译配置全部通过；
- 用户当前未提交的工程配置和控制参数改动保持不变。
