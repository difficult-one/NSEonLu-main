# 在线参数掉电保存

用户要求补齐在线调参后的掉电保存与恢复。继续支持实时应用、电脑源码同步，新增板端自动持久化。

每次成功 SET 标记待保存。只有底盘零力、全部已注册 DJI 电机停用且反馈静止持续 100 ms，并且控制快照新鲜时，低优先级任务才保存；检查与写入期间暂停任务调度，防止重新使能输出。网页独立显示保存状态，等待期间提示退出运动模式。失败不自动反复擦写，提供重试。USB 断开不取消已应用参数的待保存工作。

选择双扇区追加日志，而非原地覆盖或每次擦除：STM32F407 扇区 10/11 分别为 128 KiB，链接代码限制为前 768 KiB。每条固定 512 字节记录包含 schema、序号、已注册组掩码、各组模式和 float32 位模式、CRC32、最后编程的提交标记。写满时只擦除另一个扇区，保留当前最新有效记录；启动扫描选择最新完整记录。相同配置不重复写入。

启动优先级为：有效且模式匹配的 Flash 配置 → 电脑参数覆盖文件 → 原始固件默认。Flash 内容还要经过原有组约束校验，失败回退。更换 schema 或编译模式不恢复不匹配组。正常按使用区域烧录保留参数；全片擦除会清除参数。

现有 @T1 OK 回复追加可选保存状态字段（saved/pending/error/volatile/unsupported），旧回复仍可读取但不宣称掉电保存。SAVE 请求只重试已生效的指定版本；后台查询仅更新保存状态，不覆盖正在编辑的草稿。

验证：模拟 NOR Flash 每个字编程点断电、半擦除、CRC/提交标记损坏、双扇区轮换、去重、序号回绕；验证恢复优先级、模式隔离、失败重试和断线；浏览器验证待保存、成功、失败、重试和草稿保留；构建与链接分区检查。不会自动烧录或宣称实物掉电验收完成。
