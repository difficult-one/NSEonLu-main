# 电机相关数据类型详解

> 涵盖 `motor_def.h`、`dji_motor.h`、`dmmotor.h`、`HT04.h`、`LK9025.h`、`power_control.h`

---

## 数据类型总览

```
motor_def.h  (公共类型，所有电机共用)
├── 枚举 (6个)
│   ├── Closeloop_Type_e      — 闭环类型选择
│   ├── Feedfoward_Type_e     — 前馈类型
│   ├── Feedback_Source_e     — 反馈来源
│   ├── Motor_Reverse_Flag_e  — 电机正反转
│   ├── Feedback_Reverse_Flag_e — 反馈正反
│   ├── Motor_Working_Type_e  — 启停状态
│   └── Motor_Type_e          — 电机型号
│
├── 结构体 (4个)
│   ├── Motor_Control_Setting_s   — 控制配置 (运行时，所有电机实例共用)
│   ├── Motor_Controller_s        — 控制器 (运行时)
│   ├── Motor_Controller_Init_s   — 控制器初始化参数
│   └── Motor_Init_Config_s       — 电机初始化总配置 (通用入口)

各电机自己的类型:
├── DJI_Motor_Measure_s / DJIMotorInstance              (dji_motor.h)
├── DM_Motor_Measure_s  / DMMotorInstance               (dmmotor.h)
├── HTMotor_Measure_t   / HTMotorInstance               (HT04.h)
├── LKMotor_Measure_t   / LKMotorInstance               (LK9025.h)
└── (PowerControl 复用 DJIMotorInstance)                 (power_control.h)
```

## 第一部分：公共类型 `motor_def.h`

### 1.1 `Closeloop_Type_e` — 闭环类型

```c
typedef enum {
    OPEN_LOOP                = 0b0000,  // 开环，纯前馈
    CURRENT_LOOP             = 0b0001,  // 电流环
    SPEED_LOOP               = 0b0010,  // 速度环
    ANGLE_LOOP               = 0b0100,  // 角度环（位置环）

    // 预定义的组合（仅用于检查，代码中用 | 运算组合）：
    SPEED_AND_CURRENT_LOOP   = 0b0011,  // 速度+电流双环
    ANGLE_AND_SPEED_LOOP     = 0b0110,  // 角度+速度双环
    ALL_THREE_LOOP           = 0b0111,  // 角度+速度+电流三环
} Closeloop_Type_e;
```

**位掩码设计**：每个位对应一个环，可以组合。例如 `ANGLE_LOOP | SPEED_LOOP` 表示启用角度环和速度环（双环控制）。

**判断时**：`if (close_loop_type & ANGLE_LOOP)` 判断是否启用角度环。

---

### 1.2 `Feedfoward_Type_e` — 前馈类型

```c
typedef enum {
    FEEDFORWARD_NONE                = 0b00,  // 无前馈，纯 PID 反馈
    CURRENT_FEEDFORWARD             = 0b01,  // 电流前馈（重力补偿、摩擦补偿）
    SPEED_FEEDFORWARD               = 0b10,  // 速度前馈（预估稳态电流）
    CURRENT_AND_SPEED_FEEDFORWARD   = CURRENT_FEEDFORWARD | SPEED_FEEDFORWARD,  // 两者都有
} Feedfoward_Type_e;
```

> 注意代码中拼写错误：应为 Feed**for**ward。

---

### 1.3 `Feedback_Source_e` — 反馈来源

```c
typedef enum {
    MOTOR_FEED = 0,   // 使用电机自带的编码器和计算出的速度
    OTHER_FEED,        // 使用外部反馈源（如 IMU、外部编码器）
} Feedback_Source_e;
```

| 值 | 含义 | 场景 |
|----|------|------|
| `MOTOR_FEED` | 电机自带传感器 | 底盘（编码器）、摩擦轮 |
| `OTHER_FEED` | 外部传感器 | 云台（IMU 角度）、小陀螺模式 |

---

### 1.4 `Motor_Reverse_Flag_e` — 电机正反转

```c
typedef enum {
    MOTOR_DIRECTION_NORMAL  = 0,  // 正向
    MOTOR_DIRECTION_REVERSE = 1,   // 反转（pid_ref 乘 -1）
} Motor_Reverse_Flag_e;
```

---

### 1.5 `Feedback_Reverse_Flag_e` — 反馈正反

```c
typedef enum {
    FEEDBACK_DIRECTION_NORMAL  = 0,  // 反馈不反转
    FEEDBACK_DIRECTION_REVERSE = 1,   // 反馈取反
} Feedback_Reverse_Flag_e;
```

与电机反转不同，它反转的是**反馈量**（measurement），而非目标值（reference）。

---

### 1.6 `Motor_Working_Type_e` — 启停状态

```c
typedef enum {
    MOTOR_STOP    = 0,  // 停止（输出强制置零）
    MOTOR_ENALBED = 1,   // 使能（正常响应设定值）
} Motor_Working_Type_e;
```

---

### 1.7 `Motor_Type_e` — 电机型号

```c
typedef enum {
    MOTOR_TYPE_NONE = 0,
    GM6020,     // 云台电机 (角度闭环)
    M3508,      // 底盘电机 (速度闭环)
    M2006,      // 拨弹电机
    LK9025,     // 大疆 LK 电机
    HT04,       // 宇树 HT04 电机
} Motor_Type_e;
```

---

### 1.8 `Motor_Control_Setting_s` — 控制配置

```c
typedef struct {                       // 大小 ≈ 5 字节
    Closeloop_Type_e outer_loop_type;          // 外层闭环（ANGLE/SPEED）
    Closeloop_Type_e close_loop_type;          // 启用几个闭环（位掩码）
    Motor_Reverse_Flag_e motor_reverse_flag;   // 输出是否反转
    Feedback_Reverse_Flag_e feedback_reverse_flag; // 反馈是否反转
    Feedback_Source_e angle_feedback_source;   // 角度数据来源
    Feedback_Source_e speed_feedback_source;   // 速度数据来源
    Feedfoward_Type_e feedforward_flag;        // 前馈类型
} Motor_Control_Setting_s;
```

**用途**：决定一个电机"怎么控制"——用哪个环、反馈从哪来、是否反转。运行时**只读**，初始化时设定后一般不改。实例中的成员名为 `motor_settings`。

---

### 1.9 `Motor_Controller_s` — 运行时控制器

```c
typedef struct {                              // 大小 ≈ 64 字节
    float *other_angle_feedback_ptr;           // → 外部角度反馈地址（IMU 等）
    float *other_speed_feedback_ptr;           // → 外部速度反馈地址
    float *speed_feedforward_ptr;              // → 速度前馈值地址
    float *current_feedforward_ptr;            // → 电流前馈值地址

    PIDInstance current_PID;                   // 电流环 PID 实例
    PIDInstance speed_PID;                     // 速度环 PID 实例
    PIDInstance angle_PID;                     // 角度环 PID 实例

    float pid_ref;                             // ★ 目标值（Application 写入，控制循环读取）
} Motor_Controller_s;
```

**实例中成员名**：`motor_controller`

---

### 1.10 `Motor_Controller_Init_s` — 控制器初始化参数

```c
typedef struct {
    float *other_angle_feedback_ptr;   // → 外部角度反馈源
    float *other_speed_feedback_ptr;   // → 外部速度反馈源
    float *speed_feedforward_ptr;      // → 速度前馈源
    float *current_feedforward_ptr;    // → 电流前馈源

    PID_Init_Config_s current_PID;     // 电流环 PID 参数
    PID_Init_Config_s speed_PID;       // 速度环 PID 参数
    PID_Init_Config_s angle_PID;       // 角度环 PID 参数
} Motor_Controller_Init_s;
```

**设计意图**：将 PID **参数**（Kp/Ki/Kd/MaxOut 等）与 PID **状态**（误差累积、输出历史）分离。这里存参数，`Motor_Controller_s` 存状态。

---

### 1.11 `Motor_Init_Config_s` — 电机总初始化结构体（通用入口）

```c
typedef struct {
    Motor_Controller_Init_s controller_param_init_config;     // PID 参数
    Motor_Control_Setting_s controller_setting_init_config;    // 控制配置
    Motor_Type_e motor_type;                                    // 电机型号
    CAN_Init_Config_s can_init_config;                          // CAN 配置
} Motor_Init_Config_s;
```

**所有类型的电机统一使用这个结构体初始化**：

```c
Motor_Init_Config_s config = {
    .can_init_config = { .can_handle = &hcan1, .tx_id = 1 },
    .controller_param_init_config = { .speed_PID = {...}, ... },
    .controller_setting_init_config = { .outer_loop_type = SPEED_LOOP, ... },
    .motor_type = M3508,
};
DJIMotorInstance *motor = DJIMotorInit(&config);     // DJI
HTMotorInstance *motor  = HTMotorInit(&config);     // HT04
LKMotorInstance *motor  = LKMotorInit(&config);     // LK9025
DMMotorInstance *motor  = DMMotorInit(&config);     // DM
```

## 第二部分：各电机自己的类型

### 2.1 DJI 电机 `dji_motor.h`

#### `DJI_Motor_Measure_s` — 测量值

```c
typedef struct {
    uint16_t last_ecd;              // 上次编码器值 (0-8191)
    uint16_t ecd;                   // 本次编码器值
    float angle_single_round;       // 单圈角度 (度)
    float speed_aps;                // 角速度 (度/秒), 低通滤波
    int16_t real_current;           // 实际电流, 低通滤波
    uint8_t temperature;            // 温度 (°C)

    float total_angle;              // 总角度 (多圈), 度
    int32_t total_round;            // 总圈数
} DJI_Motor_Measure_s;
```

#### `DJIMotorInstance` — 完整实例

```c
typedef struct {
    DJI_Motor_Measure_s measure;           // 测量值
    Motor_Control_Setting_s motor_settings; // ← 复用公共类型
    Motor_Controller_s motor_controller;   // ← 复用公共类型
    CANInstance *motor_can_instance;       // CAN 实例
    uint8_t sender_group;                  // 发送组 0-5
    uint8_t message_num;                   // 组内编号 0-3
    Motor_Type_e motor_type;               // 电机型号
    Motor_Working_Type_e stop_flag;        // 启停
    DaemonInstance *daemon;                // 看门狗
    uint32_t feed_cnt;                     // 反馈计数
    float dt;                              // 两次反馈时间间隔
} DJIMotorInstance;
```

### 2.5 PowerControl — 特殊，复用 DJIMotorInstance

```c
// power_control.h — 直接用 DJIMotorInstance
DJIMotorInstance *PowerControlInit(Motor_Init_Config_s *config);
void PowerControl(void);
void SetPowerLimit(float power_limit);
```

功率控制**不改电机数据结构**，而是在 `PowerControl()` 中通过修改 DJI 电机实例内部的 `motor_controller.pid_ref`（或直接修改 PID 输出）来实现**功率限制**。

## 第三部分：各电机类型的复用程度对比

| 电机类型 | Motor_Control_Setting_s | Motor_Controller_s | Measure 结构体自定 | 控制架构 |
|---------|:---:|:---:|:---:|------|
| **DJI** | ✅ 复用 | ✅ 复用 | ✅ `DJI_Motor_Measure_s` | 集中式 `DJIMotorControl()` |
| **DM** | ✅ 复用 | ❌ 展开（代码重复） | ✅ `DM_Motor_Measure_s` | 每实例一个 RTOS 任务 |
| **HT04** | ✅ 复用 | ❌ 展开（代码重复） | ✅ `HTMotor_Measure_t` | 每实例一个 RTOS 任务 |
| **LK9025** | ✅ 复用 | ❌ 展开（代码重复） | ✅ `LKMotor_Measure_t` | 集中式 `LKMotorControl()` |
| **PowerControl** | ✅ 复用 | ✅ 复用 | ✅ 复用 DJI 的 | 集中式 `PowerControl()` |

## 第四部分：类型之间的依赖关系

```
Motor_Init_Config_s
├── CAN_Init_Config_s                     (bsp_can.h)
│   ├── CAN_HandleTypeDef *can_handle
│   ├── uint32_t tx_id / rx_id
│   └── void (*can_module_callback)()
│
├── Motor_Controller_Init_s               (motor_def.h)
│   ├── PID_Init_Config_s × 3            (controller.h)
│   │   ├── Kp, Ki, Kd
│   │   ├── MaxOut, IntegralLimit
│   │   └── Improve (位掩码)
│   └── 四个反馈/前馈指针
│
├── Motor_Control_Setting_s               (motor_def.h)
│   └── 6 个枚举字段
│
└── Motor_Type_e                          (motor_def.h)
```

**初始化后的运行时**：

```
Motor_Controller_s (运行时状态)
├── PIDInstance × 3 (含误差累积、上次输出等)
├── 四个指针 → 指向外部数据
└── pid_ref ← Application 写入

Motor_Control_Setting_s (运行时只读)
└── 初始化后一般不再修改
```

## 第五部分：结构体嵌套路径速查

```c
DJIMotorInstance motor;

// 读取当前角度
motor.measure.total_angle

// 读/写 PID 参考值
motor.motor_controller.pid_ref

// 修改闭环类型
motor.motor_settings.close_loop_type

// 判断是否反转
motor.motor_settings.motor_reverse_flag

// 访问 PID 参数
motor.motor_controller.speed_PID.Kp

// 切换反馈来源
motor.motor_controller.other_angle_feedback_ptr = &imu->YawTotalAngle;
```
