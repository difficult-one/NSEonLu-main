# 仪表盘单轮 PID 自动整定

用户已批准集成到现有 USB 仪表盘，使用架空固定、四轮离地的台架。网页搜索参数，板端执行可重复的单轮阶跃，先测试基线，再搜索 Kp/Ki（Kd 保持读取值），独立复测后推荐，用户点击采用才正式应用并同步文件、排队保存 Flash。可选择单轮或依次四轮。架空结果需要落地验证，不承诺全局最优。

## 运行边界

- 新增“自动整定”页签，沿用本地 Node 服务、原生 JS/CSS 和现有串口连接；不增加依赖。
- 台架准入要求遥控器反馈在线且不超过 100 ms、左拨杆下/右拨杆中、四摇杆和拨轮绝对值不超过 30、无键鼠按键、无跟随模式、正常控制有效且四轮目标接近零；控制快照不超过 10 ms，四轮电机反馈不超过 20 ms，开始时四轮不超过 50 rpm。
- 保留电流限幅、功控和裁判保护。只允许一个轮子运动；非测试轮发送零电流。测试目标 100～1500 电机 rpm，默认 500；保持 500～2000 ms，默认 1000；临时电流上限 500～5000 原始单位，默认 3000，且不超过原轮限幅。
- 控制周期统计 RMSE、正向超调、最终 20% 区间绝对误差、5%误差带稳定时间、电流总变差和限流占比。升速前 300 ms 归零等待，测试后 300 ms 归零。限流占比超过 5% 的试验无效；无足够反馈、超速、CAN 失败、操纵遥控器、通信心跳超时立即停止。
- 每 200 ms 请求状态以续租，租期 1000 ms；单会话最长 180 秒。退出、断连和异常在板端恢复原 PID 并释放锁，输出保持停机直到遥控器进入零力。页面丢失不依赖 JS 恢复。
- 候选直接覆盖电机任务的临时 PID，正式参数组及其版本保持不变；会话期间拒绝手动 SET/SAVE，暂停 Flash 保存，GET 可读。结束后恢复原值。采用前重新读取并核对基线版本，防止覆盖别人的修改。

## 协议与模块

与 CSV 和 @T1 共用串口，新增 @A1 行，float 参数沿用 IEEE754 八位十六进制：

```
@A1,id,BEGIN,pid_revision
@A1,id,TRIAL,session,wheel,rpm,hold_ms,current_cap,kp_hex,ki_hex,kd_hex
@A1,id,STATUS,session
@A1,id,END,session
@A1,id,OK,session,state,wheel,trial,reason,samples,rmse_milli,overshoot_milli,settle_ms,steady_milli,jitter_milli,limited_pm
@A1,id,ERR,reason
```

state 为 idle/ready/running/done/aborted。reason 为 none/stopped/timeout/guard/feedback/overspeed/limited/no_response/config/can。DONE 数据保留直到下一次 TRIAL；END 恢复原值后释放会话。协议一次一个请求，TRIAL 只确认已开始，不等待整个实验。纯 C 引擎与协议服务分离，电机任务独占引擎，USB 任务只投递请求和发送快照。

## 网页搜索与结果

读取 24 项原参数，保留非搜索字段。基线有效才搜索：Kp 为当前值的 0.75/1/1.25 倍（限制 0.01～5）；Ki 为当前值、0、0.5、1、2（限制 0～10）；去重后最多 15 组。评分以归一化 RMSE 为主，叠加超调、稳态误差、稳定时间和电流波动惩罚。每轮最佳候选独立复测，复测相对基线改善至少 5% 才推荐。四轮结果合并后一次正式 SET，GET 核对版本，显示文件同步和板端保存两个独立状态；文件失败支持重试，不重复应用。

演示为独立的合成台架，不向串口发送命令、不写文件；明确显示演示标记。切换实时/调参/整定页不停止采集；整定过程中禁用手动调参操作。网页展示进度、当前与最佳指标、参数对比、所选轮目标/实际转速图和实验表。

## 验证

主机 C 测试验证引擎阶段、反馈新鲜度、停机、心跳超时、回绕、限流剔除、指标和协议；DJI 集成测试验证临时参数恢复、单轮输出、停止优先级。JS 测试验证搜索、复测、无改善恢复、断连和旧版本冲突。运行原有遥测/持久化回归，构建 USB 遥测及视觉固件，浏览器验证三页签、演示整定和窄屏。实物烧录与台架验收由用户执行。
