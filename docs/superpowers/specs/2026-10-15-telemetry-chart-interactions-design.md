# 遥测仪表盘按键稳定性与波形交互

状态：用户已确认弹窗方案，已完成实现与软件验证。

## 范围与交互

修复 USB 遥测仪表盘在未接收任何数据时键盘和鼠标按键反复高亮的问题。无数据、遥控器离线或数据过期时统一显示未按下；有效数据到达后按实际位图更新。

功率、缓冲能量及四轮转速三个波形区域均可点击放大，并提供明确的“放大”按钮及键盘入口。推荐使用原生 dialog 显示大图，保留曲线名称、颜色和单位；Esc、关闭按钮和点击遮罩关闭并返回原位置。相比原位撑开卡片，此方式不推动仪表盘布局。弹窗和原卡片使用同一个显示快照，实时和暂停语义一致。

在普通图和放大图内移动鼠标时显示竖向定位线、采样位置及读数框。以鼠标横坐标对应的最近真实采样为准，显示相对窗口末端的时间、板端 tick（ms）和该采样的各条曲线值（W、J 或 rpm）。离线与无效来源显示“—”；不插值、不用邻近有效数值代替无效值。通信断点和超过 500 ms 的空白不吸附到远处采样。移出绘图区或没有样本时隐藏提示。

## 实现边界

保留现有普通 JavaScript、Canvas、本地服务与 60 秒/3000 点滚动窗口。不引入运行依赖，不更改串口协议或固件。charts.js 维护绘图坐标和悬停覆盖层，app.js 传入带中文名称的曲线定义并管理放大弹窗；HTML/CSS 提供响应式弹窗与提示样式。暂停时打开、缩放或关闭弹窗仍会重绘冻结快照，不影响继续采集。
