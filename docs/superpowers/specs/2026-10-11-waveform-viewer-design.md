# 本地平滑波形工具设计

提供中文、无需安装且可断网使用的本地 HTML 工具，读取项目已有 CSV 或粘贴内容，按字段勾选并叠加波形。目标数据规模为十万行以内。

## 数据处理

CSV 第一条非空记录是唯一、非空字段名的表头。支持 UTF-8/BOM、引号/转义、LF/CRLF、重复表头和动态列数。非法数字形成断点，列数或引号用法错误的记录跳过并报告物理行号；未闭合引号拒绝本次导入，原有成功数据保留。

横轴优先为数值字段 tick、tick_ms（毫秒），其次采样序号，允许手动切换。数据保持输入顺序。每个字段在缺失数据、重复或倒退横轴处分段。

PCHIP 平滑连接当前采样值，不修改数值、不产生过冲。每字段额外滤波默认关闭；开启时使用居中移动平均，窗口为 3～101 的奇数，默认 5 点，边缘截断窗口，跨断点不混合。所有重算以原始数组为输入。已滤波字段 p_filtered_cw 提示已有滤波，只有用户开启才额外处理。

## 界面与交付

左侧文件/粘贴入口和字段复选框、滤波开关、窗口；右侧横轴选择、图例、Canvas 曲线、可选点、水平缩放平移及复位。纵轴跟随可见曲线自动缩放。悬停使用完整数据，显示实际最近样本的横轴、物理行号、原始值及额外滤波值。所有数值保留输入单位。

普通脚本通过相对路径加载，兼容 file://；不使用 fetch、CDN、ES 模块、网络服务或持久化。职责分为纯计算 core.js、Canvas 和交互 plot.js、界面及导入 app.js。提供说明和示例 CSV；不修改固件或其他现有工作区改动。

## 验证

用 Node 原生测试验证 CSV、分段、均值和插值；在隔离的 Windows Edge 中验证 file:// 加载、断网交互、错误恢复、十万行文件导入和视图操作。密集显示保留屏幕列内的首尾、最小和最大点，不减少滤波及查询的数据。
