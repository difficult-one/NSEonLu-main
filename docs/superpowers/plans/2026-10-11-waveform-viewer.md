# 本地平滑波形工具实施计划

目标：在 tools/waveform-viewer 提供离线 CSV 字段选择、平滑绘图和可选独立滤波。使用普通 HTML/CSS/JavaScript、Canvas 和 Node 原生开发测试；无需应用安装或构建。设计见对应 waveform-viewer-design 文档。

1. 先用真实 CSV、手算均值、插值端点及密集尖峰样本建立失败测试，再实现 core.js 的 CSV 解析、动态列识别、断点分段、原始数据移动平均、PCHIP、二分查询和峰谷简化。
2. 编写浏览器验收脚本并验证能检测未加载页面；实现响应式中文界面、独立字段配置、导入失败保留原数据、图例和原始单位提示。
3. 用 Canvas 将三次 Hermite 多项式转换为贝塞尔路径，添加可见纵轴适配、鼠标/键盘缩放平移、复位、独立悬停覆盖层和完整采样查询。
4. 验证 Node 测试、断网 file:// 浏览器流程、项目 17/26 列数据、采集导出格式和十万行交互；处理实际失败，并独立审查代码。
5. 提供示例 CSV 与使用说明，只暂存本工具及对应文档，创建本地 Git 提交并报告提交编号。
