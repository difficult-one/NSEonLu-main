# 同向正弦自转

## 目标与范围

保留固定自转和已实测可用的功率自适应自转，增加独立正弦目标模式。正弦负责周期快慢节奏，现有缓冲预算、实测功率闭环和最终电流/功率保护负责实际输出。

新增 `CHASSIS_SPIN_MODE`：0 固定、1 功率自适应、2 正弦。未显式配置时沿用 `CHASSIS_SPIN_ADAPTIVE_ENABLE` 的现有选择；工作区用户刚开启的开关保持为未提交修改。Make/CMake 可覆盖模式。三种模式均作用于原 `CHASSIS_ROTATE`，不改双板命令或遥测布局。

## 波形和方向

当前默认目标为 `s * (800 + 200 * sin(2*pi*t/4))`，采用项目现有 wz 命令单位，不称作电机 rpm。方向 s 默认为 +1，可配置为 -1，在进入自转时锁定；只变化幅值，退出/关闭输出后才解除方向锁。2026-10-15 修复将正弦中心和起步速度从固定/自适应模式参数中分离，见文末验证记录。

正弦参数独立：中心 800、起步速度 200、振幅 200、周期 4 s、振幅渐入时间 1 s、目标上升速率上限 400、下降速率上限 2000 命令单位/s。该波形稳态最大变化率约 314，正常完整波形范围 600..1000，配置必须保证波谷为正且在正弦模式上下限内。固定/自适应仍使用原来的 4000、1000..6000 参数。

进入时从正弦最小正目标 200 起步，连续满足追踪/保护允许条件 200 ms 后按限速升至基准 800，再逐渐放开振幅，避免零目标令既有驱动需求判断无法退出 IDLE。真实电机电流仍由已有启动保护限制。

正弦模式允许健康低需求状态建立下一次驱动需求：瞬态状态为 RUN 或 IDLE，功率计/轮速/时序有效、无故障和制动，且驱动需求为零时，可累计稳定确认。这样纯比例速度环跟上最低目标后，不会因电流降到需求门限以下而永远卡在最低目标；波谷制动结束后也可恢复上升。已有驱动需求时仍需瞬态驱动许可；STARTUP、CLAMP、RECOVERY、OFFLINE 不允许增长。固定和自适应的许可逻辑保持原样。

## 功率与能量协调

- 上调目标需要上述瞬态资格、既有 `increase_allowed` 和稳定确认，不跳过四轮在线、追踪、电流上限、预测保护和制动门槛。
- 正弦相位按有效控制 dt 推进，限流时也继续推进；不积累或追赶错过的波峰。
- 当前或低通功率高于目标时降低自转中心，同时收缩振幅；仅恢复到配置基准，不额外追着余量提高正弦中心。
- 限流或缓冲恢复时收缩振幅，暂停正向增长；有健康电容支持时，现有预算仍决定可用负载功率。
- 需求预算回落不会按功率比缩放中心、振幅和当前目标，也不重置稳定确认。缓冲增补的正常撤销不改变健康正弦节奏；2026-10-16 的解耦修复见 `2026-10-16-sine-buffer-decoupling-design.md`。
- 实测超功率、限流或能量恢复仍按上述门槛收缩转速包络；目标上升和下降均受变化率限制。最终功率和电流硬保护仍立即约束输出，无需等待目标转速降低。

反馈失效取消调制、返回同方向低速目标并重新等待稳定；输出关闭或退出自转返回 0 并清除状态。非法配置/数值/异常 dt 返回 0，清除正弦状态。最低目标不能强行开启已被既有保护禁止的电流输出。

## 验证与交付

正弦主机测试覆盖完整周期、正负方向保持、启动/渐入限速、保护阻止增长、缓冲恢复与过功率收紧、预算下降、相位不积压、退出/失效重入、非法配置/状态/dt。保留旧固定与自适应测试，并用具有功率响应延迟的独立负载验证保护条件。

增加真实瞬态控制器与自转算法的组合测试：采用 50 ms 低拖曳速度响应、等效速度比例增益 4.5、驱动电流需求 200/100 门限、轮速追踪门限 500。验证从静止进入后能超过最低目标，周期制动期间不增长，制动结束后恢复下一次上升；单步变化仍受限。另逐项检查低需求许可的故障、反馈、时序和瞬态状态门槛。该仿真用于发现组合逻辑死锁，不是已标定的实机负载模型。

回归动态缓冲、外环、瞬态、功率上限及 DJI 最终保护测试。构建固定、自适应、正弦，以及正弦电容配置；每种模式使用独立 build 子目录，避免 make 参数改变但旧对象未重编译。

交付正弦专用 BIN 和选择方式，不自动刷写硬件。实机比较目标/实测轮速波形、功率峰值和最低缓冲值；试验参数不代表已验证的落地转速、防命中效果或完整正弦跟踪能力。

## 验证结果与使用

2026-10-13：五个自转配置测试通过（旧固定、旧自适应、正弦、新模式覆盖旧开关的固定/自适应），其中正弦测试包含真实瞬态控制器的组合测试。动态缓冲、功率外环、瞬态、持续过功率和 DJI 最终电流/RTT 回归测试通过。独立审查发现并修正了低需求启动/波谷恢复停滞，复审无阻塞问题。

四个 ARM Make 固件配置均构建成功：固定、自适应、正弦直供、正弦电容。只有已有的 BMI088/机器人配置提示和 libnosys 系统调用链接警告。Make/CMake 已透传模式选项；当前环境没有可用的 CMake 命令，因此未验证 CMake 构建。

直供正弦测试固件：`build/spin-sine/basic_framework.bin`；电容正弦测试固件：`build/spin-sine-supercap/basic_framework.bin`。两者使用当前工作区已有硬件和控制参数。切换模式时使用独立构建目录，避免旧对象复用：

```powershell
make -j4 BUILD_DIR=build/spin-sine CHASSIS_SPIN_MODE=2
```

模式 0 为固定，1 为自适应，2 为正弦；未指定模式继续沿用旧开关。正弦参数集中于 `modules/algorithm/chassis_spin_config.h`。方向默认为 +1，需要反方向时配置 `CHASSIS_SPIN_SINE_DIRECTION=-1`，一次自转过程中保持锁定。全部验证均为主机测试和构建，尚未刷写或实机验收。
