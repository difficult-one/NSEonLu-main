# C 板 USB 遥测与网页仪表盘设计

状态：用户已确认，软件实现与验证已完成。尚未烧录 C 板或执行实物 USB 验收。

## 目标

C 板通过现有 USB CDC 虚拟串口向电脑持续发送底盘、遥控器、功率和缓冲能量数据。电脑浏览器直接读取串口，以仪表卡片和实时曲线显示，并能导出 CSV 日志。

首版用于观察和调试，不增加网页控制电机或修改功控参数的功能。

## 方案比较与推荐

| 方案 | 使用方式 | 取舍 |
| --- | --- | --- |
| 本地网页 + Web Serial（推荐） | 电脑用 Edge / Chrome 打开网页，点击连接并选择 C 板端口 | 不需要串口转发程序；浏览器需要支持 Web Serial，并由用户授权访问串口 |
| 本地串口转发服务 + 网页 | 程序读取串口，再通过 WebSocket 向网页转发 | 可覆盖更多浏览器，但需要安装、启动和维护额外服务 |
| 先保存 CSV，再用现有波形工具查看 | 采集完后打开日志 | 改动最少，但不能满足实时观察的主要目标 |

推荐第一种：网页文件放在项目内，提供本地启动入口，以 localhost 提供页面；不增加云端数据库或数据上传。本方案按本地工具交付，不注册或发布托管站点。

参考：[Chrome Web Serial 指南](https://developer.chrome.com/docs/capabilities/serial)、[Web Serial API](https://developer.mozilla.org/en-US/docs/Web/API/Web_Serial_API)、[Edge 串口访问策略](https://learn.microsoft.com/en-us/deployedge/microsoft-edge-policies/defaultserialguardsetting)。上线实现时用特性检测处理浏览器或策略不支持的情况。串口访问必须由用户点击连接触发。

## 已有工程事实

- `Src/usb_device.c` 已注册 USB CDC，`Src/freertos.c` 的默认任务负责启动 USB。
- `bsp/usb/bsp_usb.c` 已提供发送封装，CDC 接口具有发送完成和接收回调。
- `application/robot_def.h` 当前启用了 `VISION_USE_VCP`，`VisionSend()` 由姿态任务持续调用。遥测必须与视觉 USB 输出互斥，不能把二进制视觉包混入 CSV。
- `DJIChassisPowerGetSnapshot()` 能原子复制四电机及功控状态。
- 遥控器当前只有初始化返回的内部指针，需要增加只读快照入口。
- 裁判功率、功率计、超级电容模块已有状态读取入口。
- 底盘缓冲能量估计与预算结果保存在 `application/chassis/chassis.c` 内，需要发布小型遥测快照。
- `EstimateSpeed()` 尚未实现，因此网页不能把控制指令显示为整车实测速度。
- 现有 `tools/waveform-viewer` 能读取带表头的 CSV，可继续查看本次导出的日志。

## 数据内容与含义

| 分组 | 首版字段 | 单位与来源 |
| --- | --- | --- |
| 链路 | 协议版本、序号、发送 tick、数据源 tick、发送丢弃计数 | 序号按采样递增；时间为毫秒，方便识别缺行、板卡重启和数据年龄 |
| 底盘 | 控制模式、底盘坐标系 Vx / Vy 指令、最终 Wz 指令 | 来自本周期坐标变换和模式处理后的控制量；Vx / Vy 显示为控制原始单位，不标成 m/s |
| 遥控器 | 在线状态、左右摇杆四通道、拨轮、左右三档开关、鼠标 X / Y、鼠标左右键、键盘位图 | 摇杆为现有减去 1024 偏置后的值；开关保留现有 1 / 3 / 2 编码 |
| 四电机 | 各轮目标转速、实际转速、最终电流命令、反馈电流、在线掩码、使能掩码 | LF / RF / LB / RB 固定顺序；转速为 rpm；电流保留 DJI 原始命令/反馈单位，不直接标成 A |
| 功率 | 功率计实测功率、模型未限流/限流后总预测功率、裁判功率上限、名义预算、目标功率、最终模型功率限制 | 功率统一换算后显示 W；明确区分实测值、模型值和预算 |
| 缓冲能量 | 裁判原始缓冲能量、保守估算下限、预测能量、恢复状态、缓冲控制是否启用、估算有效状态 | 显示 J；原始裁判读数与算法估算分别标注 |
| 超级电容 | 在线状态、输出使能、故障码、能量比例、报告底盘功率、可用功率上限、输入功率反馈及在线状态 | 能量比例显示 %；不用百分比推算未提供的实际焦耳值 |
| 数据有效性 | 裁判、功率计、功控、缓冲估计、电容及遥控器的有效/在线标志和可用样本年龄 | 无效值在网页显示“—”或离线，不把零值当成有效测量 |

首版不实现整车实际 Vx / Vy / Wz 估计，不新增传感器采样，不修改现有功率算法、控制增益或机械参数。

## 固件架构与实时性

1. 在 `modules/telemetry` 增加专用 USB 遥测模块与配置，默认 50 Hz，即每 20 ms 取一次最新快照。发送任务使用低于电机控制的优先级。
2. 底盘任务在本周期控制和预算更新完成后发布紧凑快照；遥控器模块增加只读快照接口；电机、裁判、功率计和电容复用已有快照/状态接口。
3. 快照复制使用短临界区，格式化和 USB 发送均放在临界区外。每个来源内部一致，不承诺不同来源在同一个硬件时刻采样；保留来源 tick，便于判断年龄。
4. 使用静态发送缓冲。发送成功后，底层仍持有的数据在发送完成前不得覆盖；发送忙时丢弃本次新样本并计数，不积压历史样本。
5. USB 未初始化、未枚举或断开时直接跳过，禁止解引用空的 CDC 类状态，也不循环等待主机。
6. CDC 控制请求保存并返回有效的 line coding，跟踪串口打开/关闭状态。重新连接或重新打开串口后重新输出表头。
7. 接收回调只处理链路需要的内容；本次不增加电机控制指令入口。
8. 新增一个 USB 用途配置，选择“遥测”或“原有视觉”。遥测模式关闭视觉在 USB 上的注册和持续发送；视觉模式保留原行为。UART 视觉分支不占用 USB。

## 传输格式

- 使用固定字段顺序、唯一字段名、带版本列的 ASCII CSV，行以 CRLF 结束。
- 表头在连接开始时发送，并每 1 秒重发，允许网页中途接入或恢复解析。重复表头不计入数据样本。
- 数值采用定点整数：功率后缀 `_cw` 表示 0.01 W；估算能量后缀 `_cj` 表示 0.01 J；能量比例后缀 `_pm` 表示千分比。网页统一换算为 W / J / %。
- 底盘控制原始量统一乘 1000 后四舍五入为整数，字段后缀 `_milli`，网页除以 1000 恢复控制原始值；不使用 `printf` 浮点支持。
- 数值非有限或超范围时执行明确的无效标记/饱和处理，不能输出 NaN、Infinity 或截断行。网页使用有效标志决定是否显示数值。
- 单行和表头各使用 2048 字节静态缓冲，包含终止符；超过缓冲时丢弃整行并计数。USB 的 64 字节端点包不等同于 CSV 行，允许一行跨多个包。
- 网页逐块解码、按换行组帧，不假定一次串口读取正好是一整行。对超长残行设上限，错误后丢弃至下一个换行重新同步。

## 网页呈现

新增 `tools/usb-telemetry`，使用无构建依赖的 HTML / CSS / JavaScript，配套本地启动说明。视觉沿用现有波形工具的中文、清晰单位和卡片风格。

| 区域 | 内容 |
| --- | --- |
| 顶部工具栏 | 连接 / 断开、连接状态、接收频率、样本年龄、缺行/坏行统计、暂停显示、导出 CSV |
| 关键数值 | 实测底盘功率、功率限制、裁判缓冲能量、能量估算下限、电容能量比例 |
| 功率与能量曲线 | 功率实测/模型/目标按 W 对比；缓冲原始/估算/预测按 J 对比，分别绘图 |
| 底盘与电机 | 底盘模式与指令；四轮目标/实际 rpm 对比；电流命令、反馈和电机在线状态 |
| 遥控器 | 摇杆二维位置、拨轮条、左右档位、鼠标按键、键盘状态及遥控器在线状态 |
| 设备状态 | 裁判、功率计、电容、功控和缓冲估计状态；用文字配合颜色区分有效、离线和故障 |

曲线默认显示最近 60 秒，50 Hz 下最多保留约 3000 条滚动样本。渲染与接收解耦，显示刷新上限 20 Hz；暂停只冻结呈现，串口仍继续读取。

提供明确标注的演示数据入口用于无硬件预览，演示和真实串口数据不能混合。导出包含表头的原始 CSV，可在现有波形工具继续分析。首版导出最近滚动窗口，不增加无限时长录制。

网页不主动申请串口权限；用户点击连接后选择 C 板虚拟串口。取消选择正常返回未连接状态。端口占用、浏览器不支持、没有新样本和 USB 拔出分别给出可操作提示；断连后释放 reader 和端口，支持再次连接。

真实数据超过 500 ms 未更新时标记陈旧并使曲线断开，避免旧值看起来仍在更新。源设备离线时相应曲线也断开。板卡 tick 或序号回退时开始新片段，不画跨重启连线。

## 验证与验收

- C 主机测试覆盖 CSV 字段数量、换算、边界值、无效状态、缓冲不足、忙/断连及发送缓冲生命周期。
- JavaScript 测试覆盖任意串口分片、半行、多行、重复表头、坏行恢复、版本不符、tick 回退、滚动容量和 CSV 导出。
- 浏览器用演示数据和可控串口替身验证连接取消、收流、暂停/恢复、拔出/再次连接、数据陈旧提示、导出以及宽窄窗口布局。
- 构建 ARM 固件，并运行受影响的电机功控、遥测及遥控器相关现有检查；需要两种 USB 用途都能构建。
- 实物验收：浏览器选中 C 板端口后能连续看到约 50 Hz 数据；拨动摇杆、切换档位、变化轮速时对应显示更新；与现有调试变量核对 W / J / rpm 单位；拔插 USB 后能重连。
- 无实物或未执行烧录时，交付明确区分软件测试通过和实物验证待完成。

## 实现记录

- 交付入口与完整 72 列协议：[USB 遥测仪表盘说明](../../../tools/usb-telemetry/README.md)。
- 默认使用 `USB_TELEMETRY_ENABLE=1`；设为 `0` 可恢复原有 USB 视觉通信。
- 固件新鲜度检查：底盘快照 100 ms，模型/功率计/电容 20 ms，遥控器 100 ms，裁判 300 ms；网页整体陈旧阈值 500 ms。
- 网页按接收到的完整快照显示有效值，直到下一帧或整条链路陈旧，避免 50 Hz 接收和 20 Hz 显示相位差造成读数闪烁。
- 单个电机的在线状态独立于功率模型有效状态；功率模型失效时仍能观察有效电机反馈。
- 两种 USB 模式的 ARM 固件均构建成功；C 主机测试、跨 C/JavaScript 协议测试和浏览器交互/布局检查通过。
