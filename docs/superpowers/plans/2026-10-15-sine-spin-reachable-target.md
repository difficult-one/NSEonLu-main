# 正弦自转可达目标修复计划

**目标：** 修复正弦模式在当前 50 W 台架预算下不能建立振幅的问题，同时保留功率、反馈和电流保护。

**根因：** 振幅只在中心达到 4000 后渐入；当前运动学将该中心转换为约 22689 rpm。现有功率模型在该转速、零电流时即预测四轮总功率约 153 W，无法在 50 W 预算下满足跟随和最终保护条件。旧组合测试未运行基础限流与预测电流保护，并让负载直接跟随目标。

**方案：** 正弦单独配置中心和起步速度，采用中心 800、起步 200、振幅 200、周期 4 s、上升限速 400。默认麦轮几何下，稳态目标对应约 3403..5672 rpm。继续使用原有正弦状态机及全部保护。固定和自适应参数不变；不修改用户已有的模式、PID、功率与遥测调参。

**技术：** C11、主机 GCC、GNU Make、STM32F407 ARM GCC。

- [x] 增加使用默认配置、实际功率模型、基础限流及最终预测保护的闭环测试；先验证现有配置无法产生周期转速。
- [x] 添加正弦专用中心和起步宏并接入应用，调整正弦默认振幅和上升速率；自转回归测试显式指定模式，避免测试名称与用户模式配置冲突。
- [x] 运行自转和功率保护回归；独立目录构建正弦 USB 固件及固定/自适应配置。
- [x] 独立审查无阻塞问题；同步配置文档，并按本任务补丁提交，保留已有调参。

**验证边界：** 主机负载是独立的一阶惯性模型，仅验证控制链可建立波形，不能代替上板测量。交付固件但不自动刷写；实机需同时比较目标与实际 rpm，观察至少三个 4 s 周期。

**验证结果：** 6 个自转配置/算法测试及瞬态、持续过功率、外环、动态缓冲、DJI 最终保护 5 套回归通过。50 W→35 W→50 W 扰动后，连续三个周期的模拟实际轮速为 3384..5647 rpm，周期重复平均差小于 0.1 rpm，预测保护功率峰值 47.1 W。旧参数覆盖重跑同一测试时，无法形成周期波形，测试失败。

固定、自适应、正弦 USB 三种 ARM 配置均成功构建，分别位于 `build/sine-fix-fixed`、`build/sine-fix-adaptive`、`build/sine-fix-usb`。显式参数均含 `UART1_USE=0`、`USB_TELEMETRY_ENABLE=1`、`CHASSIS_POWER_CONTROL_STAGE=3`。正弦 BIN 为 `build/sine-fix-usb/basic_framework.bin`，122068 字节，SHA-256 为 `FAAF736EC2E5F8AE6AFDBA43CD5D25F5E7D2FBEFD71569327E65F4F4581A691B`。编译器在沙箱中启动报 DLL 重定位错误，正常环境构建通过；仅有既有传感器/机器人配置提示及 libnosys 系统调用链接警告。
