# 底盘功率控制

## 架构

框架只保留一套 DJI 电机注册、反馈解析、PID 和 CAN 发送流程。所有 DJI 电机通过 `DJIMotorInit()` 注册，并由 `DJIMotorControl()` 统一控制。

四个底盘 M3508 额外注册为一个功率管理组。`DJIMotorControl()` 每周期先计算所有电机的原始 PID 输出，再对底盘组执行功率分配和限流，最后统一打包并发送 CAN 报文。云台、拨弹等非底盘电机不会进入底盘功率分配。

## 控制流程

```text
ChassisTask 设置四轮速度目标和裁判功率上限
    ↓
DJIMotorControl 计算所有 DJI 电机 PID 输出
    ↓
PowerModelApply 处理底盘四电机
    ├─ 预测原始功率
    ├─ 按速度误差分配总功率
    ├─ 求解电流衰减系数
    └─ 输出限流后的四轮电流
    ↓
DJIMotorControl 统一执行启停、CAN 打包和发送
```

## 数据单位

- `MecanumCalculate()` 的四轮结果沿用 `rpm`；
- `DJIMotorSetRef()` 前乘以 `6.0f`，转换为度每秒；
- DJI 通用速度环使用度每秒；
- 功率模型在驱动挂接处除以 `6.0f`，恢复为 `rpm`；
- 电流使用 DJI 电调原始命令值；
- 功率模型计算前将电流除以 `1000.0f`；
- 功率和功率限制的单位为 W。

由于速度目标和反馈同时放大六倍，底盘速度环 `Kp` 从 `4.5f` 改为 `0.75f`，保持纯 P 环输出与迁移前等效。

## M3508 初始模型

```text
P = K0
  + K1 × I
  + K2 × speed
  + K3 × I × speed
  + K4 × I²
  + K5 × speed²
```

初始参数：

```text
K0 = 0.65213
K1 = -0.15659
K2 = 0.00041660
K3 = 0.00235415
K4 = 0.20022
K5 = 1.08e-7
current_conversion = 1000
```

这些参数来自源项目，只用于完成迁移和初步验证。正式上车前需要使用本车电机、电调、供电和负载数据重新检查或拟合。

## 功率预算与分配

有效功率预算为：

```text
裁判功率限制 × 超级电容衰减系数 × 安全系数
```

当前设置：

- 超级电容衰减系数：`1.0f`；
- 安全系数：`0.95f`；
- 四轮误差和不超过 `500 rpm` 时均分；
- 有效预算低于 `54 W` 时按误差比例分配；
- 有效预算不低于 `54 W` 时每轮先保留 `8 W`，剩余部分按误差分配；
- 最终电流命令限制在 `[-15000, 15000]`。

实车预测误差确认可接受后，可逐步把安全系数提高到 `0.98f`。不要在没有采样对比的情况下直接提高。

## 超级电容

当前超级电容协议只提供电压、电流和瞬时功率，没有明确的剩余能量百分比。现阶段不根据这些量猜测剩余能量，衰减系数固定为 `1.0f`。

后续获得能量百分比或明确的电压—能量映射后，在 `chassis.c` 中调用 `DJIChassisPowerSetAttenuation()` 更新 `[0,1]` 范围的系数，不需要修改功率模型。

## 安全行为

以下情况会把四个底盘电机的最终电流清零，不影响其他 DJI 电机：

- 裁判功率限制为零、负数或非有限数；
- 功率模型输入或输出出现 NaN/无穷大；
- 功控组注册失败；
- 对应底盘电机离线；
- 电机被 `DJIMotorStop()` 停止。

单电机方程没有有效限流解时，只清零该电机电流。高速旋转时，即使电流为零仍可能存在铁损和机械损耗，因此保底功率和整车安全系数仍然必要。

## 无裁判系统台架调试

`application/robot_def.h` 提供编译期开关：

```c
#define CHASSIS_POWER_BENCH_TEST 0
#define CHASSIS_POWER_BENCH_LIMIT_W 40.0f
```

正式固件默认且必须保持 `CHASSIS_POWER_BENCH_TEST == 0`。需要在没有裁判系统的情况下进行台架调试时，确认车轮已经完全架空，再把开关临时改为 `1` 并重新完整编译、烧录。此时裁判功率上限为零或无效才会使用 `40 W` 台架上限；裁判系统给出有效正值时仍以裁判上限为准。

调试结束后立即把开关恢复为 `0`，重新编译正式固件。台架模式不会绕过遥控器急停、电机离线保护或功率模型内部的数值检查。

## 调试

通过 `DJIChassisPowerGetState()` 可观察：

- 有效总功率预算；
- 四轮速度误差；
- 四轮原始预测功率；
- 四轮分配额度；
- 四轮电流衰减系数；
- 四轮限流前后电流；
- 四轮限流后预测功率；
- 最近一次算法状态。

建议依次验证架空轮、低速直行、急加速、横移和平移叠加小陀螺，并同步记录裁判系统实际底盘功率。

## 自动测试

在仓库根目录运行：

```powershell
make -C tests/power_model clean test
```

测试覆盖功率预测、均分、误差分配、保底功率、一次/二次方程限流、非法预算、NaN 和电流硬限幅。
